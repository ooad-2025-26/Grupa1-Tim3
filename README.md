# eVrtić Sistem

eVrtić Sistem je ASP.NET Core MVC web aplikacija namijenjena za upravljanje radom vrtića. Aplikacija omogućava rad sa korisnicima različitih uloga: roditelj, odgajatelj i administrator.

## Funkcionalnosti

- Registracija i prijava korisnika
- Različiti prikazi za roditelja, odgajatelja i administratora
- Upravljanje djecom i grupama
- Evidencija dnevnih aktivnosti djeteta
- Pregled dnevnih izvještaja
- Uređivanje profila korisnika
- Validacija unesenih podataka na formama

## Tehnologije

- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- ASP.NET Identity
- Bootstrap / CSS


## Deployment

Aplikacija je dostupna na linku:

```text
evrtic.onrender.com
```
